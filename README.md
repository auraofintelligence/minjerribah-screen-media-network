# Minjerribah Screen & Media Network

A cinematic, multi-page public invitation connecting existing film, local-media,
training, noticeboard, Ballow Road, sand-sport and long-horizon transport
workbenches.

The site is deliberately source-honest:

- active public prototypes stay separate from official projects;
- proposals are labelled as proposals;
- the Quandamooka Festival, QUAMPI and cultural authority are not claimed;
- Ready S.E.T. Co-op is not presented as an already formed entity;
- community screens do not replace emergency authorities; and
- tunnels, park-and-ride and spoil reuse remain future questions, not engineering
  plans.

## Edit the content

Most shared lists, links and editable planning allowances live in
`data/site-content.ts`. Page copy lives in `components/`.

## Run locally on Windows

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local address shown in the terminal.

## Check both publishing builds

```powershell
npm.cmd test
```

The project produces:

- a vinext build for private preview and Sites hosting; and
- a separate static multi-page build in `pages-dist/` for GitHub Pages.
